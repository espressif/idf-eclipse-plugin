Support Policy
==============

:link_to_translation:`zh_CN:[中文]`

Espressif-IDE and the ESP-IDF Eclipse plugin reach the end of feature development with version 4.5.0. This policy covers both the standalone Espressif-IDE application and the ESP-IDF Eclipse plugin installed from the update site.

The same policy is published on GitHub as `SUPPORT_POLICY.md <https://github.com/espressif/idf-eclipse-plugin/blob/master/SUPPORT_POLICY.md>`_.

------

v4.5.0 is the final release that adds features. During the maintenance period, bug fixes for high-severity issues and security fixes are applied. Maintenance releases, if required, are published as 4.5.x.

On 8 October 2027, Espressif-IDE and the ESP-IDF Eclipse plugin reach end of life. After that date, new features, bug fixes, and security fixes are no longer provided. A formal end-of-life advisory will be published when maintenance ends.

Releases before 4.5.0 receive no further updates. Use 4.5.x for the remainder of the maintenance period.

Developers are encouraged to move existing projects to the `ESP-IDF extension for VS Code <https://docs.espressif.com/projects/vscode-esp-idf-extension/en/latest/>`_ before 8 October 2027.
